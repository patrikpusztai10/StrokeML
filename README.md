The dataset which was used in this project:
https://www.kaggle.com/datasets/ozguraslank/brain-stroke-ct-dataset/data
<br>
In this project I analyze the performance of a hybrid VGG16 and XGBoost model, ResNet50 and a hybrid AlexNet and SVM model in accurately detecting ischemic and hemorrhagic strokes in CT
scans.
Contributions:
1. Found and processed an unbalanced dataset with around 10000 CT scans in DICOM format
2. Implemented the machine learning models for multiclass classification using libraries like TensorFlow,
3. Evaluated their performance using metrics like Accuracy, F1-Score, Recall achieving F1-scores over 0.95 for the
hybrid approaches
4. Used the Optuna library for hyperparameter tuning
